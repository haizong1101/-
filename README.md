# Bunny English 小兔英语 🐰

面向 3 岁半零基础幼儿的英语启蒙 App（MVP 原型）。可爱风格、语音交互、字母描红，可在手机 / iPad 浏览器中运行，支持添加到主屏幕（PWA）。

产品方案见 [docs/产品方案.md](docs/产品方案.md)。

## 功能

- **四个主题岛**（动物岛 / 颜色泡泡 / 美食街 / 身体小屋）：17 个关卡，每关 2 个新词，走"听 → 看 → 说 → 玩 → 奖励"流程
- **开口说（语音交互）**：Web Speech API 端侧识别 + 小词表模糊匹配，三档宽松评价（发音接近大力表扬 / 有发声鼓励重试 / 没发声温柔跳过），不支持识别的设备自动降级为跟读模式
- **字母火车（ABC Train）**：全部 26 个字母（按书写难度排序），含字形认知、字母音 Phonics、手指描红（超宽容差判定）、戳气球辨认、跟读
- **Letter Match 首字母配对**：学会 6 个字母后解锁，把字母和以它开头的单词配对
- **Magic Words 魔法口令（TPR）**：孩子说 jump / spin / eat / sleep，小兔做对应动作；也可点卡片触发
- **贴纸博物馆**：完成关卡收集贴纸（60 格收藏墙）
- **家长中心**：算术题门禁、每日时长上限（默认 15 分钟，到点强制休息）、学习报告
- **隐私**：语音由浏览器本地识别，不上传、不存储任何录音；无广告、无账号

## 开发

```bash
npm install
npm run dev      # 本地开发
npm run build    # 产物在 dist/
npm run preview  # 预览构建产物
```

> 语音识别（麦克风）需要 HTTPS 或 localhost 环境；iPad/iPhone 建议用 Safari，Android 建议用 Chrome。
