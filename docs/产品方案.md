# 幼儿英语启蒙 App 产品方案

> 目标用户：3 岁半左右、几乎零英语基础的幼儿
> 运行平台：手机 / iPad（iOS、Android、平板均可运行）
> 风格定位：可爱、温暖、低刺激
> 核心特色：语音交互（听、跟读、简单对话）

---

## 1. 教育理念与设计原则

针对 3 岁半零基础幼儿，方案遵循以下幼教原则：

1. **听说优先，不教读写**：这个年龄段的孩子处于语言习得的"沉默期"，重点是大量"磨耳朵"输入 + 鼓励开口模仿，不出现字母拼写、单词认读等抽象内容。
2. **TPR 全身反应教学法**：指令类互动（"Touch your nose!" "Jump!"），让孩子用动作回应语言，符合幼儿"动中学"的特点。
3. **单次时长严格控制**：每节课 5–8 分钟，每日建议不超过 15 分钟，内置强制休息与护眼提醒。
4. **零挫败感**：没有"答错"的惩罚，任何发声尝试都获得正向反馈；不设排行榜、不设竞争。
5. **场景化、生活化词汇**：只教孩子日常能接触到的事物（动物、食物、颜色、身体部位、家庭成员），让线下生活能自然复现线上所学。
6. **家长可控**：所有设置、购买、时长管理都放在带家长验证的"家长中心"内。

## 2. 产品核心玩法

### 2.1 主线结构：陪伴式 IP + 主题岛屿

- 设计一个核心 IP 角色（建议：一只圆滚滚的小兔子 **"Bunny"**，大眼睛、软色调），全程语音陪伴孩子，是"会说话的朋友"而不是"老师"。
- 世界地图由若干**主题岛屿**组成，每个岛屿对应一个主题单元：

| 阶段 | 主题岛屿 | 核心词汇（示例） | 核心句型 |
|---|---|---|---|
| 1 | 动物岛 | cat, dog, duck, pig, bird | What's this? It's a... |
| 1 | 颜色泡泡 | red, blue, yellow, green | I like... |
| 1 | 数字乐园 | one ~ five | How many? |
| 2 | 美食街 | apple, banana, milk, egg | Yummy! I want... |
| 2 | 身体小屋 | eye, nose, mouth, hand | Touch your... |
| 2 | 我的家 | mommy, daddy, baby | This is my... |
| 3 | 玩具房 | ball, car, doll, bear | Where is...? |
| 3 | 天气花园 | sunny, rainy | It's sunny! |

- 每个岛屿 6–8 个关卡，词汇量控制在每关 2–3 个新词（幼儿短时记忆上限）。

### 2.2 单关卡流程（约 5 分钟）："听 → 看 → 说 → 玩"

1. **磨耳朵（听）**：Bunny 用夸张语调 + 动画展示新词，同一个词多语境重复 3 次以上（"A cat! Look, a cat! Meow~ cat!"）。
2. **认一认（看）**：语音指令点选互动——"Where is the cat? Tap the cat!"，点对了角色欢呼撒花。
3. **开口说（说）**：**语音交互核心环节**，见第 3 节。
4. **玩一玩（游戏化复习）**：拖拽喂食、戳泡泡、贴纸拼图等小游戏，把本关词汇再复现 3–5 次。
5. **奖励**：获得一枚贴纸，收集进"贴纸博物馆"；Bunny 唱一小段儿歌庆祝。

### 2.3 辅助模块

- **儿歌台**：10–20 首经典启蒙儿歌（自制或使用无版权曲目），带跟唱动画，作为纯输入型"磨耳朵"内容。
- **贴纸博物馆**：收集成就的展示墙，是幼儿最直接的激励系统。
- **家长中心**（算术题门禁）：学习报告（今天听了什么、开口了几次、跟读录音回放）、每日时长设置、休息间隔设置。

## 3. 语音交互方案（核心特色）

### 3.1 三种语音互动模式

1. **跟读模仿（主力）**
   - Bunny 说 "Say: cat!" → 麦克风开启 3 秒 → 孩子发声 → 评价反馈。
   - 评价策略：**三档宽松制**。检测到近似发音 → 大力庆祝；检测到任意发声 → "Good try! Listen again~" 再示范一次；没有发声 → 温柔鼓励后跳过，绝不卡关。
2. **语音指令游戏（TPR）**
   - 反向互动：孩子对着屏幕说词，对应物体做出反应（说 "jump!" 小兔子就跳）。识别目标只有本关 2–3 个词，命中率高、成就感强。
3. **简单问答**
   - "What's this?" → 孩子说出单词即算对。只做**关键词匹配**，不做自由对话（3 岁幼儿发音不稳定，自由对话体验会崩）。

### 3.2 技术实现

- **语音识别（ASR）**：
  - 首选设备端原生识别：iOS `SFSpeechRecognizer` / Android `SpeechRecognizer`（Web 端为 Web Speech API），免费、低延迟、语音不出设备，利于隐私合规。
  - 识别策略：**小词表匹配**——只在本关 2–3 个目标词内做模糊匹配（编辑距离 + 常见幼儿音变映射，如 cat→"ca"、"tat" 也算通过），大幅提高幼儿语音的"识别成功率"。
  - 进阶（二期）：接入 Azure Speech / 声网 / 讯飞的儿童发音评测 API，给家长端提供更精细的发音报告（孩子端永远只有鼓励）。
- **语音合成（TTS）**：
  - MVP 阶段**优先使用真人配音**（童声或亲切女声录制全部固定台词），比 TTS 更可爱、更稳定；动态内容兜底用系统 TTS。
- **兜底体验**：麦克风权限被拒或识别不可用时，"说"环节自动降级为"再听一遍 + 点选"，流程不中断。

### 3.3 儿童隐私合规（必须做）

- 语音只在本地识别，**不上传、不存储原始音频**（家长中心的跟读回放功能默认关闭，开启需家长明确同意，且仅存本机）。
- 无第三方广告、无社交功能、无对外分享。
- 遵循 COPPA / 《儿童个人信息网络保护规定》：不收集儿童个人信息，账号体系挂在家长名下。

## 4. 视觉与声音风格

- **视觉**：
  - 软萌圆润风：全部圆角、粗描边、大头身比角色；马卡龙低饱和色板（奶油黄、淡粉、薄荷绿、天空蓝），避免高饱和强刺激配色。
  - 超大可点击区域（≥ 96pt），全程无文字依赖——所有按钮用图标 + 语音提示，孩子不识字也能独立操作。
  - 动画节奏舒缓，无快速闪烁（防光敏、防过度刺激）。
- **听觉**：
  - 语速放慢至正常 0.8 倍、语调夸张上扬的"幼儿导向语"（motherese）。
  - 轻快但音量克制的背景音乐，可在家长中心关闭。
- **交互**：只用"点、拖、说"三种操作，无双击、无长按、无滑动返回等复杂手势。

## 5. 技术选型

| 层面 | 方案 | 理由 |
|---|---|---|
| 应用框架 | **Web（PWA）优先，Capacitor 打包上架** | 一套代码覆盖手机 + iPad + 浏览器；开发调试最快；Capacitor 可桥接原生语音 API 与应用商店分发 |
| 前端 | React + TypeScript + Vite | 生态成熟，动画与状态管理方便 |
| 动画 | CSS 动画 + Lottie（角色动效） | Lottie 适合可爱角色的骨骼动画，包体小 |
| 语音识别 | Web Speech API（Web）/ 原生 ASR（Capacitor 插件） | 免费、端侧、低延迟 |
| 语音播放 | 预录音频（Howler.js 管理） + TTS 兜底 | 音质与"可爱度"可控 |
| 数据存储 | 本地存储（IndexedDB / Capacitor Preferences） | MVP 无需后端，天然合规 |
| 后端（二期） | 轻量云函数 + 家长账号同步 | 多设备进度同步时再引入 |

> 说明：不选 Flutter/RN 的原因——MVP 阶段 Web 技术栈迭代最快，且本项目交互以 2D 动画 + 音频为主，Web 完全胜任；后期若需要更强的原生能力再评估迁移。

## 6. MVP 范围与路线图

### 第一阶段：MVP（可玩原型）
- 1 个 IP 角色（Bunny）+ 主界面地图
- 2 个主题岛屿（动物岛、颜色泡泡），共 10 个左右关卡
- 完整"听 → 看 → 说 → 玩"关卡流程
- 跟读语音交互（三档宽松评价）+ 降级方案
- 贴纸奖励系统 + 每日时长控制 + 家长门禁
- 中文家长界面 / 全语音儿童界面

### 第二阶段：内容扩充
- 新增 4 个主题岛屿；儿歌台上线
- 语音指令 TPR 游戏
- 家长学习报告

### 第三阶段：打磨与上架
- Capacitor 打包 iOS / Android，接入原生 ASR
- 发音评测 API（家长报告用）
- 多孩子档案、云端进度同步

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 幼儿发音识别率低导致挫败 | 小词表模糊匹配 + "任何发声都表扬"的三档策略 |
| 孩子沉迷或过度用眼 | 强制单课时长 + 每日上限 + 20 分钟护眼休息动画 |
| iPad Safari / 各浏览器语音 API 差异 | 能力探测 + 自动降级为点选模式 |
| 音视频素材成本 | MVP 用少量真人录音 + 程序化动画；儿歌选用无版权曲目 |
| 儿童隐私合规 | 端侧识别、不存音频、无广告、家长门禁 |
